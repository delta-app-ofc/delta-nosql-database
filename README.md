# Delta NoSQL Database

Repositório para armazenar os scripts de criação e configuração das coleções MongoDB do Projeto Delta.

## Estrutura

- `collections/` — Definições de schema e estrutura de cada coleção
- `indexes/` — Scripts de criação de índices
- `scripts/` — Scripts de seed/carga inicial de dados
- `script-collections.js` — Script principal de criação das coleções
- `script-indexes.js` — Script principal de criação dos índices
- `script-roles.js` — Configuração de Custom Roles e governança de acesso
- `script-seed.js` — Dados iniciais (referências, enums)
